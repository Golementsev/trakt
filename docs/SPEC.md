# Тракт — продуктовая спека

Интерфейс на русском. Один пользователь, локально. Утверждённый UI — `mockup/trakt.html`.

## 1. Сущности

### Проект (доска)
- `name`, `key` (2–5 заглавных букв, префикс номеров задач: `PAY-12`).
- `repoPath` — локальная папка с кодом, в которой агент работает над задачами (опционально).
- Свои статусы, типы задач, шаблоны, воркфлоу, настройки агента, условие готовности.
- Новый проект создаётся со стандартным набором (см. «Значения по умолчанию»).

### Статус (колонка)
- `name`, `color`, `category`: `todo` | `doing` | `done`, `position`.
- Категория — подсказка агенту: `doing` = можно работать, `done` = закрыто.
- Удаление статуса: задачи из него переезжают в соседний левый (или первый). Минимум 2 статуса.
- Новый статус получает переходы в/из всех остальных статусов.

### Тип задачи
- `name`, `color`, `position`. Минимум один тип на проект.
- Удаление типа: задачи переходят в первый тип.

### Поле шаблона (для конкретного типа)
- `name`, `kind`: `text` | `number` | `date` | `checkbox`, `required`, `visibleToAgent`, `position`.
- Поля `text` рендерятся в окне задачи отдельными блоками **под описанием**.
- Остальные — компактной строкой ниже.
- `visibleToAgent` = поле попадает в контекст агента (в макете — метка «AI»).
- Название, описание и сабтаски есть у любой задачи, это не поля шаблона.

### Воркфлоу
- Матрица разрешённых переходов `fromStatus → toStatus`.
- Проверяется **на сервере** для всех: и для UI, и для агентов.
- По умолчанию разрешено всё, кроме прыжка из первых двух статусов сразу в «Готово».

### Задача
- `number` (сквозной в проекте), `title`, `typeId`, `statusId`, `position` в колонке,
  `description`, значения полей шаблона, `agentOwned` (bool — задачу ведёт агент),
  `claim` (кто из агентов сейчас держит задачу и до когда), `createdAt`, `updatedAt`.
- Черновик в БД не пишется: живёт на клиенте, пока не нажато «Создать».

### Сабтаска
- `title`, `done`, `state`: `idle` | `running` | `done` | `failed`, `position`.
- Лог прогона агента: строки прогресса со временем.

### Прогон агента (run)
- Запуск агента на сабтаске или задаче: `status`, `startedAt`, `finishedAt`, `agentName`,
  лог, итоговый отчёт. Можно остановить.

### Событие (лента)
- Каждое изменение: кто (`you` или имя агента), что, над какой задачей, заметка, время.
- Показывается в строке под шапкой (последнее), в «Ленте» и в истории задачи.

### Настройки агента (на проект)
- `canMove` — агент сам двигает задачи.
- `maxStatus` — не дальше этого статуса (по умолчанию «Ревью»: в «Готово» переводит человек).
- `autoTake` — агент сам берёт задачи из второго статуса («К работе»).
- `canCreate` — агент может создавать задачи (по умолчанию выкл).
- `definitionOfDone` — текст: когда агент вправе двигать задачу дальше.

### Идея
- Текст, опциональный AI-ответ, дата. Можно превратить в задачу (открывается черновик).

## 2. Экраны и поведение

### Шапка и боковая панель
- Слева: список проектов со счётчиком задач, «+ Новый проект», блок статуса агента.
- Шапка: название и ключ проекта; переключатель стримлайнов «Нет / Тип / Агент»;
  тумблер «Агент двигает задачи» (глобальная пауза); «Лента»; «Настройки»; «+ Задача».
- Под шапкой строка с последним событием.
- Узкий экран: боковая панель скрыта, проект выбирается в шапке.

### Доска
- Колонки = статусы, по порядку. Заголовок: цвет, название, счётчик; при наведении:
  ← →, «+» (задача в эту колонку), «×» (удалить статус). Заголовок можно перетащить.
- Последняя колонка — форма «+ Новый статус» с выбором «после какого».
- Стримлайны сворачиваются кликом по заголовку дорожки.
- Карточка: номер, заголовок, чип типа, прогресс сабтасок, индикатор «агент работает».
- Drag&drop карточек между колонками и дорожками. Переход, запрещённый воркфлоу,
  подсвечивается красным и не выполняется, с тостом.
- Перенос в другую дорожку меняет соответствующее свойство (тип или «ведёт агент»).
- Изменения, сделанные агентами, появляются сразу (живое обновление), карточка мигает.

### Окно задачи (по центру)
- Шапка: номер, чип типа, «агент работает», «▶ Отдать агенту» / «Забрать у агента», удалить, закрыть.
- Тело: см. порядок в `DECISIONS.md`. Заголовок и поля редактируются на месте, сохраняются автоматически.
- Статус — степпер, только чтение.
- Сабтаски: чекбокс, название, «▶ Агент» / «■ Стоп» / «готово», лог прогона.
  Над списком: «✦ Разбить с AI», «▶ Все агенту». Внизу: поле новой сабтаски (Enter).
- Когда все сабтаски закрыты агентом — агент переводит задачу в «Ревью» (если позволяют воркфлоу и `maxStatus`).
- Новая задача — черновик (см. `DECISIONS.md`).

### Настройки проекта (модальное окно, вкладки)
- В шапке окна — «Удалить проект»: с подтверждением, удаляет задачи, идеи и ленту проекта, останавливает его прогоны.
- **Статусы:** цвет, название, категория, ↑ ↓, удалить, «+ Статус».
- **Типы задач:** цвет, название, число задач и полей, «Шаблон», удалить, «+ Тип».
- **Шаблон задачи:** выбор типа; поля: название, вид, обязательное, видно агенту, удалить; «+ Поле»;
  текст условия готовности для агента.
- **Воркфлоу:** матрица чекбоксов «из → в».
- **Агент:** двигает сам, не дальше статуса, сам берёт задачи, может создавать задачи;
  путь к репозиторию; команда запуска агента (см. ARCHITECTURE).

### Лента
- Выезжает справа, список событий проекта.

### Кнопка «+» (идеи)
- Поле для мысли; чипы-подсказки («Идея фичи», «Что отдать агенту», «Риски»);
  «✦ Сгенерировать с AI» (стримит ответ, есть «Стоп»); «В идеи»; «Сделать задачей».
- Список сохранённых идей со «→ задача».
- В контекст AI уходит список задач текущего проекта.

## 3. Значения по умолчанию для нового проекта

- Статусы: Бэклог (todo), К работе (todo), В работе (doing), Ревью (doing), Готово (done).
- Типы и шаблоны:
  - Фича: «Критерии приёмки» (text, обязательное, видно агенту).
  - Баг: «Шаги воспроизведения» (text, обяз.), «Где воспроизводится» (text).
  - Исследование: «Главный вопрос» (text, обяз.), «Срок» (date, не видно агенту).
  - Техдолг: «Что трогаем» (text).
- DoD: «Тесты зелёные, PR открыт и привязан к задаче, в описании есть короткий отчёт что сделано.»
- Агент: `canMove=true`, `maxStatus=Ревью`, `autoTake=false`, `canCreate=false`.
