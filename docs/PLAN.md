# План реализации

Каждый этап заканчивается рабочим состоянием, которое пользователь может потрогать.
После этапа — показать, собрать фидбек, только потом дальше.

## Этап 0. Каркас
- npm workspaces: `apps/web`, `apps/server`, `packages/shared`. TypeScript, ESLint, Prettier, Vitest.
- `npm run dev` поднимает сервер (4700) и Vite с прокси. `npm run build && npm start` — один процесс.
- Перенести из макета CSS-токены (светлая/тёмная тема), шрифты (IBM Plex Sans, JetBrains Mono, Unbounded).

**Готово, когда:** открывается пустая доска с шапкой и боковой панелью как в макете.

## Этап 1. Доска без агентов
- Схема БД + миграции (`docs/schema.sql` как основа), сид демо-проекта из макета по флагу `--seed`.
- Домен и REST: проекты, статусы (с позицией и «после какого»), типы, поля шаблона, воркфлоу,
  задачи, сабтаски, события.
- UI по макету: доска, колонки (перестановка перетаскиванием и стрелками), карточки,
  drag&drop с проверкой воркфлоу, стримлайны «Нет/Тип/Агент», окно задачи по центру,
  черновик и «Создать задачу», настройки со всеми вкладками, лента, строка событий.
- SSE: изменения из другой вкладки появляются сразу.
- Тесты домена: воркфлоу, удаление статуса/типа с переносом задач, обязательные поля, позиции.

**Готово, когда:** доской можно пользоваться вручную, всё сохраняется между перезапусками.

## Этап 2. MCP
- MCP-сервер на `/mcp` + `trakt-mcp` (stdio) по контракту `docs/MCP.md`.
- Правила агента: `canMove`, `maxStatus`, `claim`, автопереход в «Ревью».
- В «Настройки → Агент»: сниппеты подключения для Claude Code, Codex, Cursor и общий JSON.
- Интеграционный тест: MCP-клиент проходит полный цикл по задаче; UI видит изменения живьём.

**Готово, когда:** пользователь подключает MCP к своему агенту, говорит «возьми PAY-12» —
и видит на доске, как агент берёт задачу, пишет прогресс и двигает её.

## Этап 3. Кнопка «▶ Агент» (push-раннер)
- Настройки проекта: `repoPath`, пресет/шаблон команды запуска, опция «отдельный worktree».
- Сборка промпта из задачи/сабтаски/полей/DoD.
- Запуск процесса, стрим stdout/stderr в лог прогона, «■ Стоп», статус прогона.
- «▶ Все агенту», «▶ Отдать агенту» / «Забрать у агента», тумблер «Агент двигает задачи» (глобальная пауза).
- `autoTake`: фоновая раздача задач из «К работе» (с лимитом параллельных прогонов, по умолчанию 1).

**Готово, когда:** нажатие «▶ Агент» на сабтаске реально запускает агента в папке проекта,
лог идёт живьём, по завершении сабтаска закрыта, задача переехала по правилам.

## Этап 4. AI-функции доски
- Выбрать с пользователем источник модели (ключ Anthropic API или через CLI).
- «✦ Разбить с AI» — предлагает сабтаски.
- Кнопка «+»: мысль, генерация со стримом и «Стоп», идеи, «Сделать задачей» (открывает черновик).

**Готово, когда:** обе функции работают, а без ключа дают понятное сообщение.

## Этап 5. Полировка
- Клавиатура: Esc, Ctrl/Cmd+Enter, Enter в сабтасках.
- Пустые состояния, ошибки сети, откат оптимистичных обновлений.
- Бэкап/экспорт БД в JSON.
